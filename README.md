# IT-Helpdesk-Ticketing-Incident-Management-Lab
Built and administered a GLPI-based IT helpdesk environment to simulate Level 1 technical support, daily IT requests, and incident-management workflows in a business environment.
- Deployed and configured a GLPI Helpdesk server in a virtualized Linux environment to support simulated IT operations.
- Created an organizational structure representing departments, employees, and IT support roles to simulate business support workflows.
- Managed IT requests through the full ticket lifecycle, including creation, categorization, prioritization, assignment, troubleshooting, escalation, and resolution.
- Supported simulated end-user incidents involving Microsoft 365, network connectivity, storage, and peripheral equipment.
- Maintained IT support documentation and created standardized troubleshooting procedures for recurring technical issues.

.sql file contains a log recording every action taken throughtout the lab

.pdf file is a report summarizing environment configuration, oganizational structure and ticketing process
